Aide

Circuit

Entrée : webhook GLPI (/webhooks/glpi) ou formulaire natif — même résultat, même circuit.

  1. Validation : admin, en attente
  2. IP : réservation IPAM (phpIPAM)
  3. VM : clone Terraform sur Proxmox
  4. Post-install : compte admin, clé SSH, root fermé, playbooks du catalogue
  5. Notification : commentaire sur le ticket GLPI si la demande en vient

Pages

  • Connexions : Proxmox, phpIPAM, GLPI, Gitea, LDAP — bouton de test par connexion
  • Catalogue : tes playbooks, obligatoire ou optionnel
  • Déploiement : un playbook contre n'importe quel hôte de l'inventaire, dry-run possible
  • Inventaire : groupes et hôtes, ou régénéré depuis Proxmox
  • Sous-réseaux IPAM : /connections/<nom>/subnets, un par VLAN
  • HTTPS : certificat auto-signé ou importé
  • Utilisateurs : comptes, rôles, déverrouillage
  • Audit : docker compose exec backend tail -f /app/logs/audit.log

Support
