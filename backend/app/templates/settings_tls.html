Importer un certificat existant

Fichiers au format PEM (texte, -----BEGIN ...-----) — le format habituel livré par une autorité de certification ou généré par certbot/`openssl`.
Nécessaire si ton certificat n'est pas auto-signé : le ou les certificats intermédiaires (et/ou racine) de l'autorité qui l'a signé — souvent livré à côté par l'autorité (ex : "fullchain"/"ca-bundle"). Sans ça, certains navigateurs ou clients n'arriveront pas à vérifier la chaîne de confiance jusqu'à l'autorité.
En CLI (depuis le conteneur backend) : python -m app.cli tls set --cert cert.pem --key key.pem [--chain chain.pem], python -m app.cli tls generate --cn mondomaine.local, python -m app.cli tls status.
